## 2. 想法那句话（idea）

> 在这页上，**同一台 G1 的本体**成为那个"词"——它作为一帧真实画面，被嵌在句子中间，句子说什么，槽位里就是什么。

竞品测试：宇树官网可以说这句吗？**不能**。宇树钉住的是自家 logo 和产品渲染图；把"客户场地里的同一台机器"嵌进句子里，只有做交付的服务商才能这么说。

**全站唯一活的东西**：hero 里那个 1:1 循环槽位。点四个词（走 / 跳 / 群 / 建图），槽位里的画面立刻换成对应真实视频。这是用真素材做的、手机上拇指可点、无脚本时降级为一张静态帧。

## 3. 五级字阶（v2 是 10 级，这次收敛到 5 级）

```
--t-display  clamp(2.5rem, 7.2vw, 7.5rem)   标题 / 巨型陈述
--t-head     clamp(1.75rem, 3.4vw, 3rem)    区块标题
--t-lead     clamp(1.25rem, 1.6vw, 1.625rem) 导语
--t-body     1.0625rem (17px)               正文
--t-small    0.875rem (14px)                注脚 / 标签
```

头身比：display 120px / body 17px = **7.1 倍**（v2 是 5.0）。

## 4. 版式骨架

1. **Hero**：一句话 + 行内媒体槽位。句子永远是 1 行（已用真实字宽验证 390→1440 全通过）。
2. **导览**：真视频 + 四步板。把 v2 的 11 行表格砍到 4 步，站点信息并进一句话。
3. **群控**：**新素材** —— 展厅多机同步真实现场（这一直是"截图待补"）。
4. **动作链**：视频→SMPL→IsaacSim→MuJoCo→真机。**全新章节**，技术说服力最强。
5. **数字**：4 个真实数字，反白纸色块。全页唯一的"休息"。
6. **培训**：两天 12 学时。
7. **问答**：沿用（内容好），改成 <details>。
8. **联系**：表单复制。
