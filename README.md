# 落地组 · 产品官网

宇树 G1 / GO2 二次开发工作室的官网，纯静态：`index.html` + `assets/`，没有构建步骤，直接双击或用任意静态服务器打开。

## 本地预览

```bash
cd D:/code/unitree-site
python -m http.server 8811
# 打开 http://127.0.0.1:8811/
```

直接双击 `index.html` 也能打开（相对路径，无 fetch 依赖），只是视频与字体在某些浏览器下会受限。

## 目录

```
index.html              单页：首屏 → 三种现场 → 怎么交付 → 要几台（适配器）→ 证据 → 培训 → 问答 → 联系
assets/css/site.css     全部样式（颜色、字号、栅格、动效都是 token）
assets/js/site.js       动效与交互（首屏换帧、交付步骤切换、场地适配器、FAQ、表单复制）
assets/fonts/           拉丁字母 Epilogue + 中文 Noto Sans SC（按页面用字子集化，各约 65KB）
assets/img/             真机实拍帧（10 张）、导览方案页截图（4 张）
assets/video/           两段现场视频（巡场行走 12s、舞蹈 8s），已转 H.264 并去掉音轨
```
